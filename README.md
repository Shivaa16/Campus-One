# 🎓 Campus One — Smart Campus Management Platform

### One Platform. Every Campus Request. Fully Connected and Trackable.
```
Campus One (formerly Campus360) is a centralized, web-based campus management platform designed to simplify and digitize everyday academic and administrative processes within educational institutions.

The platform brings students, faculty, and administrators together through a unified interface, enabling efficient request management, improved transparency, and streamlined communication.

## 📌 Problem Statement

Educational institutions often rely on fragmented systems, paperwork, emails, and manual processes to manage student-related administrative requests.

This creates several challenges:

- Delays in approvals and administrative processing.
- Lack of transparency in request status.
- Difficulty tracking and managing student requests.
- Inefficient communication between students, faculty, and administrators.
- Increased paperwork and repetitive manual tasks.
```
## 💡 Our Solution

Campus One addresses these challenges by providing a single digital platform where campus-related requests can be submitted, managed, and tracked.

The platform is designed to improve operational efficiency, reduce administrative complexity, and provide a seamless user experience for all stakeholders.

## ✨ Key Features

### 📊 Centralized Dashboard
A unified dashboard that provides an organized overview of campus activities, requests, and relevant information.

### 📝 Digital Request Management
A structured interface for managing student requests, including leave applications, certificates, reimbursements, and other administrative services.

### 🔐 Role-Based Access
Dedicated user experiences for students, faculty, and administrators.

### 📍 Request Tracking
A streamlined workflow designed to improve visibility into request progress and approval status.

A clean, intuitive, and responsive design focused on usability and accessibility.

### 🌗 Light & Dark Mode
Theme support for a comfortable user experience across different environments.

An adaptable interface designed for desktops, tablets, and mobile devices.

## 🏗️ System Architecture

Campus One follows a modular approach designed to separate user-interface components, application logic, and data management.

The platform is organized around three primary user roles:

**Student → Faculty → Administrator**

Each role interacts with relevant campus services through a unified digital environment.

## 🚀 Getting Started

### Prerequisites

Ensure that the following tools are installed:

- Node.js
- npm
- Git
- Visual Studio Code (recommended)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/AlphaX-Crypto/Campus360.git
```

**2. Navigate to the project directory**

```bash
cd Campus360
```

**3. Install dependencies**

Run this command inside the directory containing `package.json`:

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit the local URL displayed in your terminal, typically:

```text
http://localhost:5173
```

*Note: If the React application is located in a frontend subdirectory, navigate there before installing dependencies.*
